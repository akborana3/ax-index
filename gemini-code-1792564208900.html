02 // Autonomous ReAct Loop

An AI agent that works the page while you watch.

The agent runs a transparent ReAct loop. It reasons about your goal, picks one browser action as JSON, reads what changed on the DOM, and repeats until the job is done. Connect any model via OpenRouter.

Live Agent Trace
Reasons first
Every step opens with a concise thought so you can see why the agent is about to act.
One JSON action per step
Actions execute sequentially against the live page and return real DOM observations.
Your choice of model
Pick any model on OpenRouter. Switching providers never breaks the browser loop.

04 // Per-App Routing

Your own proxy, for the browser only.

AxBrowser routes its traffic through Android's WebView ProxyController. No system-wide VPN slot required and no root permissions needed.

Browser-isolated
Pages load through your configured proxy while the rest of your phone stays untouched.
Authenticated proxies
Username and password challenges are handled natively the way Chromium expects.
Pairs with anti-fingerprinting
Mask your network origin while limiting what scripts can infer about your device.

FAQ // Details

Questions people ask about AxBrowser

What is AxBrowser?

AxBrowser is an open-source Android web browser with a built-in AI agent, developer tools, proxy support, ad-block and fingerprint protection. It is built with Kotlin and Jetpack Compose and updated through nightly releases on GitHub.

Where can I view the source code?

AxBrowser is 100% open source. You can browse the code, star the repo, or audit commits at github.com/akborana3/AxBrowser.

Does AxBrowser have an AI agent?

Yes. The agent runs a ReAct loop: it reasons about your goal, chooses one browser action as JSON, reads the result and repeats until the task is done. You choose the model through OpenRouter.

Can I use a proxy with a username and password?

Yes. AxBrowser sends browser traffic through your proxy using Android's WebView ProxyController and passes credentials the way Chromium expects, so authenticated proxies connect without affecting other apps on your phone.
